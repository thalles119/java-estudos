# Java Estudos

Repositório de estudos e exercícios em **Java**, criado para registrar minha
evolução na linguagem — dos primeiros conceitos até projetos mais complexos.

O conteúdo acompanha a playlist
[Maratona Java Virado no Jiraya (DevDojo)](https://www.youtube.com/playlist?list=PL62G310vn6nFIsOCC0H-C2infYgwm8SWW),
com prática diária e projetos aplicando cada novo conceito aprendido.

---

## Objetivo

Transformar teoria em prática. A cada bloco de conteúdo estudado, novos
exercícios e pequenos projetos são adicionados aqui, mostrando a progressão
**do mais simples ao mais avançado**.

---

## Organização

Os projetos são organizados por semana de estudo:

```
java-estudos/
├── semana-01-fundamentos/
│   └── ExercicioDos100Anos.java
├── semana-02-arrays/
└── ...
```

Cada pasta reúne os exercícios e mini-projetos daquele período.
